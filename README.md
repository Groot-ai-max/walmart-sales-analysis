# 🏬 Walmart Sales Data Analysis

## 📌 Overview
This project analyzes Walmart sales data to uncover trends, seasonal patterns, and store-level insights using exploratory data analysis (EDA).

---

## 🎯 Objectives
- Analyze sales trends over time
- Identify seasonal patterns
- Compare store performance
- Visualize sales distribution

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
